입력·정답 파일 작성 방법

묻고 대답 기다리기 블록의 답변을 input1.txt에 한 줄씩 씁니다. 입력이 끝난 뒤 나온 말풍선에 포함될 정답 문자열을 output1.txt에 씁니다. input2.txt / output2.txt처럼 같은 번호로 테스트를 추가할 수 있습니다.

정답 문자열이 입력 후 말풍선에 포함되면 통과합니다. 숫자만 추출하거나 소수점 오차를 임의로 허용하지 않습니다. 무한 반복·추가 입력 요구는 별도 판정하며 점수는 배점 기준 없이 자동 부여하지 않습니다.
